# GPX Visualizer — MVP

npm i
npm run dev

Умеет: загрузка GPX (кнопкой или drag-and-drop), стиль линии (цвет/толщина/обводка/градиент),
подложки (5 провайдеров, прозрачность, ч/б и др. фильтры, отключение → прозрачный PNG),
точки wpt (видимость/радиус/цвет), экспорт в PNG 1x–3x.

Известные ограничения:
- экспорт работает только с CORS-friendly тайлами (CARTO, Esri — ок);
- в старых Safari фильтр карты при экспорте не применяется (ctx.filter);
- градиент пока по длине трека, следующий шаг — по высоте (ele уже распарсен).
